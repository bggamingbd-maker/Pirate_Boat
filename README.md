# Pirate Boat Adventure

A fast, browser-based arcade game. Sail a pirate boat, collect gold coins and treasure chests, and dodge rocks, barrels, sea monsters and enemy ships. It plays instantly on desktop and mobile with no wallet and no blockchain transactions.

Built with [Arc Studio](https://studio.arc.io)

## Features

- Steer with the arrow keys, A/D, or by holding the left or right side of the screen
- Coins, treasure chests, ports to reach, and difficulty that rises as your score grows
- Pause and resume, sound effects with a mute toggle, and a best score saved on your device
- Ready for a future Arc wallet and onchain leaderboard (scores go through a single swappable provider)

## Tech stack

Vite, React, TypeScript, Tailwind CSS, HTML5 Canvas, WebAudio.

## Development

Prerequisites: [Bun](https://bun.sh).

```bash
bun install
bun run dev
```

Lint and typecheck:

```bash
bun run check
```

### Environment variables

None.
